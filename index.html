Welcome to Industrial UI Library

A lightweight modular UI industrial & IOT component library:

• Built using TypeScript & Web Components

• Lightweight, no external dependencies other than dev-dependencies

• Global styling and variables allow defining a consistent yet customizable look & feel

• Tested using vitest

• Each component is well documented

• Demo showcase (this page)

Library installation:

// TODO: npm install industrial-ui

Button

A customizable button web component with multiple style variants.

Usage:

<ind-button>Click me</ind-button>

Attributes:

Attribute Type Default Description
disabled boolean false Disable the button
icon string undefined Specify the icon name. One of: plus, minus, close, check, etc
variant string "primary" Button style variant. One of: primary, secondary, success, info, warn, danger

Public API:

isDisabled(): boolean {...}
setDisabled(value: boolean): void {...}

Events:

A CustomEvent of type 'button-click-event' is triggered when the native event 'click' is called

Knob

A customizable knob web component.

Usage:

<ind-knob></ind-knob>

Attributes:

Attribute Type Default Description
disabled boolean false Disable the knob
grid boolean false Whether to display the reference grid or not
min number 0 Specify the minimum value
max number 100 Specify the maximum value
size number 140 Specify the width/height of the object (px)
symbol string % Specify the symbol to display after the value
value number 0 Specify the current value

Public API:

isDisabled(): boolean {...}
setDisabled(value: boolean): void {...}

Events:

A CustomEvent of type 'knob-change-event' is triggered when the knob changes its value

Examples:

Basic Knob
<ind-knob></ind-knob>
Default Value
<ind-knob value="50"></ind-knob>
Disabled State
<ind-knob value="33" disabled="true"></ind-knob>
Reference Grid
<ind-knob grid="true"></ind-knob>
Symbol Change
<ind-knob value="27" symbol="°"></ind-knob>
Min & max
<ind-knob grid="true" min="16" max="32" symbol="°"></ind-knob>

Menu

A component that shows a menu relative to the parent.

Usage:

const menu: IndMenu = new IndMenu('1.5rem', '-11.5rem', 'Select theme');
menu.items = [
    {label: 'IOT Dark Pink', action: () => setTheme('iot-dark-pink') },
    {label: 'IOT Dark Green', action: () => setTheme('iot-dark-green') },
    {label: 'IOT Light Tomato', action: () => setTheme('iot-light-tomato') }
];
this._menubar?.appendChild(menu);

Menubar

A top bar component that can host user menus and other objects.
It is part of the <ind-application> component to be placed in the menubar slot.
By default it allows changing the theme.

Usage:

<div slot="menubar">
    <ind-menubar id="menubar"></ind-menubar>
</div>

This demo features a full example of the menubar component.

Sidebar

A side bar component that displays the name of the application its logo and a list of buttons.
It is part of the <ind-application> component to be placed in the sidebar slot.
In the compact mode it will display only the icons of the buttons.

Usage:

<div slot="sidebar">
    <ind-sidebar id="sidebar" name="Industrial UI"></ind-sidebar>
</div>

This is how to specify the sidebar items:

document.querySelector('#sidebar').items = [
    {
        label: "Category",
        children: [
            {label: "About", link: "#about", icon: "about"},
            {label: "Button", link: "#button", icon: "button"}
        ]
    }
];

This demo features a full example of the sidebar component.
